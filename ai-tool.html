AI-Driven Automation Test

Overview - High-level verification of user experience and visual integrity.

  • Das Problem: In der modernen agilen Softwareentwicklung übersteigt die Geschwindigkeit der Iterationen oft die Kapazität traditioneller Testautomatisierung. Herkömmliche Tools wie Selenium verlassen sich auf starre Selektoren (IDs/XPath), die bei schnellen Designänderungen leicht brechen und somit einen hohen Wartungsaufwand verursachen.
  • Die Lösung: Dieses Projekt präsentiert einen visionsbasierten Automatisierungsansatz. Durch die Nutzung der Claude 3.5 Vision API „sieht“ der Agent den Bildschirm wie ein menschlicher Tester. Er identifiziert UI-Komponenten durch Objekterkennung statt durch den zugrunde liegenden Code, wodurch die Testsuite wesentlich resistenter gegen UI-Änderungen wird.
  • Zukunftsausblick: Obwohl die aktuelle visuelle Erkennung von LLMs große Flexibilität bietet, kann sie gelegentlich instabil sein. Um eine industrielle Stabilität zu erreichen, wird in der nächsten Phase die Integration von selbst trainierten Bilderkennungsbibliotheken angestrebt. Das ultimative Ziel ist die Implementierung von „Vibe Testing“, einer autonomen, ganzheitlichen Überprüfung der Benutzererfahrung und visuellen Integrität.
