Proof of Concept — Robot Framework + Selenium

Overview

  • Goal: This proof of concept demonstrates an efficient, scalable automation approach for infotainment and navigation systems. The main objective is to validate search functions (POIs) and UI interactions under realistic conditions.

    • Technology stack

  • Framework: Robot Framework (keyword-driven).
  • Libraries: Selenium (web integration); Appium for mobile/Android Automotive is planned for the future.
  • Methodology: Data-driven testing (DDT) using CSV/Excel.

    • Demo video

    Why Robot Framework?

  • Readability: Keyword-based tests are easy for non-developers (for example product owners or manual testers) to read and review, which improves collaboration across the team.
  • Extensibility: Custom Python libraries allow the solution to grow with increasingly complex navigation systems.
  • Maintainability: Separating test logic from test data (DDT) lets you add scenarios with less churn in the core automation, which lowers long-term maintenance effort.
